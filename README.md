## Варианты шрифтов

Все три варианта собраны из одного кода, отличаются только CSS-переменными в `src/styles.css`:

| Вариант | Заголовки | Текст |
|---|---|---|
| 1 | Tercia Light, прописные | Aeroport |
| 2 | Antonym | Aeroport |
| 3 | EB Garamond | Manrope |

Переключение: кнопки «Вариант 1/2/3» в левом нижнем углу или параметр `?v=2` в адресе.
Шрифты Tercia, Aeroport и Antonym — trial-версии (`src/assets/fonts`). Символов, которых в них нет (цифры, ₽, скобки, тире, %), браузер берёт из Manrope / EB Garamond через `unicode-range`.

## Что работает

- Хедер: прозрачный на первом экране, сплошной при прокрутке и открытых панелях; активный пункт подсвечен.
- Меню «Новинки / Образы / Каталог / Бренды» с подменю (наведение или клик по пункту со стрелкой).
- Поиск с живой фильтрацией товаров, чипами и категориями.
- Корзина: добавление, количество, удаление, рекомендации «Дополните образ», итог, счётчик в иконке сумки.
- Shop the Look: открывается кнопками «Купить» и кликом по лукбуку, можно добавить вещь или весь образ.
- Слайдер «Образ сезона» (3 слайда, автопрокрутка), выбор цвета у Arcadie и Bonnie, плашки скидок.
- Карусель «Истории брендов» со стрелками и сегментной полоской.
- Esc закрывает любую панель. Ширина макета 1440, на узких экранах страница масштабируется.

## Структура

- `src/data.ts` — товары, образы, меню, тексты. Править контент здесь.
- `src/App.tsx` — компоненты страницы и панелей.
- `src/styles.css` — токены, текстовые стили, вёрстка.
- `public/img`, `public/logo` — фото и логотипы, выгружены из Figma.
